# Art authoring

Keep original exports in `sources/`, prompt records in `prompts/`, reference provenance in
`references/`, and reusable art validation specifications in `validation/`. Place
generated review evidence in the client test output. The registry lives in
[`client/assets/`](../client/assets/README.md). Runtime assets must be packaged
separately from this directory.

The first seven [Scout and expedition studies](references/initial-reference-studies.md)
include SVG masters and PNG review exports. Use the [overhead reference prompt
standard](prompts/overhead-reference-standard.md) for related authoring.
