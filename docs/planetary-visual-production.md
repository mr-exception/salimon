# Planetary visual production
Approved phase 4, 2026-11-26. Supplements [planetary environment](planetary-environment-art-direction.md), [canonical generation](canonical-planet-generation.md) and [renderer](browser-rendering-architecture.md). No new environmental mechanics. Use canonical versioned physical inputs + independent visual seed/algorithm version to derive reproducible material, palette, distribution, regional and orbital recipes; visual revision never moves resource, collision, player or save identity. No fixed planet classes or individually generated scene backgrounds.
Layer base material → blends → cracks/erosion/details → geological objects/deposits → biology → effects. Reusable rock, sand, dust/regolith, ice, basalt, organic material families; seamless varied textures, seeded rotation/tint, large-scale patterns, global coordinates; no visible grid or chunk seams. Natural gradual transitions except actual faults/cliffs/crater edges; relief through overhead shaded contours, erosion, shadows only corresponding to actual terrain, no walk-through fake cliffs. Material colors derive from geology/biology/illumination, unusual colors need plausible explanation, no random palette. Density based on geology/ecology, empty regions intentional; decorative density does not alter resources/obstacles. Deposits visible veins/organic silhouettes, distinguish nongatherable objects, depletion/remnant/marker/harvest visuals from saved state; no persistent decorative footprints/particles. Biological families coherent shape/growth/density, microbial mats/colonies possible, no fantasy forest assumption/new resource type. Rare natural landmarks from canonical data; artificial wrecks/narrative sites only approved world/narrative placement, no guaranteed interval.
Dynamic daylight from stellar position/rotation when available; different periods/tidal lock, minimum navigable visibility, local Scout lights, future suit-facing light requires separate mechanic/power approval. Natural viewport visibility, no strategy fog of war, respect physical occlusion and bounded zoom/knowledge; no graphics advantage or remote discovery. Vacuum sharp light/no airborne weather; atmosphere scattering/haze/cloud diffuse light as physically justified. Toxicity not automatically green, radiation not glowing; invisible hazards use suit instruments. Heat distortion/frost/fire/corrosion only justified and supported; exact exposure/protection/damage from domain. Weather particles follow authoritative wind/conditions, gradual transitions, no invented events/damage; low quality retains warnings; reduced flash/distortion/particles/shake. Hydrology unapproved. Sound per [atmosphere](audio-and-atmosphere.md).
Stream visible chunks + nearby preload, release distant visuals, global-coordinate reproducibility independent of arrival/load order, no physics existence by render availability. Zoom LOD removes decorative detail only, preserves essential object/cue/knowledge; chunk size/distance benchmark. Landing uses existing terrain/actual ship footprint, supports/shadows, material/thrust disturbance, no artificial circular pad/regeneration. Gas giants/stars not invented solid terrain; admission rules authoritative, extreme uns survivable environments may exist. 3D orbital texture from lower-resolution same canonical geology/ice/atmosphere/biology/regions, no hidden scanner information. 
Production: materials, composition, geological/resource families, transitions, streaming/LOD, lighting, atmosphere/hazard cues, orbit consistency, acceptance. Four reference environments starting site, airless, hazardous, cold; reuse existing bodies or dev fixtures for missing combos, no forced catalog expansion. Actual browser captures and domain invariants, not visual-only claims.
